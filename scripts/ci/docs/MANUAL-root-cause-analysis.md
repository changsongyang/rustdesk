# root-cause-analysis.sh 使用手册

## 概述

`root-cause-analysis.sh` 是一个用于构建错误根因分析的脚本工具，基于历史构建数据和错误模式，自动识别构建失败的根本原因并提供修复建议。

## 适用场景

- 构建失败后的根本原因分析
- 重复出现的构建问题排查
- 自动化错误诊断和修复建议
- 构建问题趋势分析

## 前置条件

### 系统要求
- **操作系统**: Linux / macOS / Windows (WSL2)
- **Shell**: Bash 4.0+

### 依赖工具
| 工具 | 说明 | 是否必需 |
|------|------|----------|
| GitHub CLI (gh) | 获取构建历史 | 推荐 |
| grep | 文本搜索 | 必需 |
| awk | 文本处理 | 必需 |

## 安装步骤

### 1. 获取脚本
```bash
# 克隆仓库
git clone https://github.com/rustdesk/rustdesk.git
cd rustdesk

# 确保脚本可执行
chmod +x scripts/ci/root-cause-analysis.sh
```

## 参数说明

### 命令行参数

| 参数 | 缩写 | 说明 | 默认值 |
|------|------|------|--------|
| `--help` | `-h` | 显示帮助信息 | - |
| `--repo` | `-r` | 指定仓库 | `changsongyang/rustdesk` |
| `--run` | `-R` | 指定构建运行 ID | 最新失败构建 |
| `--history` | `-H` | 分析最近 N 次构建 | 10 |

## 使用示例

### 示例 1: 分析最新失败构建的根因
```bash
./scripts/ci/root-cause-analysis.sh
```

**输出示例**:

### 示例 2: 分析指定构建
```bash
./scripts/ci/root-cause-analysis.sh -R 25991888570
```

### 示例 3: 分析历史构建趋势
```bash
./scripts/ci/root-cause-analysis.sh -H 20
```

## 根因分类

### 代码问题
- 语法错误
- 未定义标识符
- 类型不匹配
- 逻辑错误

### 依赖问题
- 缺失依赖
- 版本不兼容
- 缓存问题

### 环境问题
- 环境变量未设置
- 路径配置错误
- 权限不足

### 网络问题
- 下载失败
- 连接超时
- DNS 解析失败

### 工具问题
- 工具未安装
- 工具版本过旧
- 工具配置错误

## 置信度评估

| 置信度 | 说明 |
|--------|------|
| 高 | 明确的错误信息，有历史修复记录 |
| 中 | 可能的原因，需要进一步验证 |
| 低 | 推测的原因，需要更多信息 |

## 常见问题

### 问题 1: 无法获取历史构建数据

**错误信息**:
```
error: Failed to fetch build history
```

**解决方案**:
```bash
# 确保已登录 GitHub CLI
gh auth login
```

### 问题 2: 分析结果不准确

**可能原因**:
- 错误模式不明确
- 历史数据不足
- 错误信息不完整

**解决方案**:
```bash
# 使用更详细的分析
./scripts/ci/root-cause-analysis.sh -v
```
