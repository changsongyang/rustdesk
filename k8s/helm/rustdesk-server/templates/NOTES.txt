恭喜！RustDesk 服务端已成功安装。

== RustDesk 服务组件 ==

本 Chart 部署了以下组件：
1. **HBBS (RustDesk ID Server)**: 版本 {{ .Values.replicaCount }} 副本
   - 端口: TCP/UDP 21115, UDP 21118
   - 功能: ID 注册和中继服务

2. **HBBR (RustDesk Relay Server)**: 版本 {{ .Values.replicaCount }} 副本
   - 端口: TCP 21116, TCP 21117
   - 功能: 数据中继服务

== 获取服务信息 ==

获取所有 Services:
  kubectl get svc -n {{ .Release.Namespace }}

获取 HBBS 服务:
  kubectl get svc -n {{ .Release.Namespace }} -l app.kubernetes.io/component=hbbs

获取 HBBR 服务:
  kubectl get svc -n {{ .Release.Namespace }} -l app.kubernetes.io/component=hbbr

== 检查部署状态 ==

检查 Pods:
  kubectl get pods -n {{ .Release.Namespace }}

查看 Pod 日志:
  kubectl logs -n {{ .Release.Namespace }} -l app.kubernetes.io/component=hbbs
  kubectl logs -n {{ .Release.Namespace }} -l app.kubernetes.io/component=hbbr

== 配置客户端 ==

在 RustDesk 客户端配置中，设置以下服务器地址：
- ID Server: hbbs.{{ .Release.Namespace }}.svc.cluster.local 或 <NodeIP>:32115
- Relay Server: hbbr.{{ .Release.Namespace }}.svc.cluster.local 或 <NodeIP>:32116
