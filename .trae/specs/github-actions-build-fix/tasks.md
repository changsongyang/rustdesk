## 风险和注意事项

1. **风险**：修改 hwcodec 可能影响其他依赖该项目的产品
   - **缓解**：仔细审查所有变更，确保向后兼容

2. **风险**：性能监控可能显示构建时间增加
   - **缓解**：优化构建缓存，确保依赖下载时间最小化

3. **注意**：Rust 版本必须保持 1.81，不进行升级
   - **缓解**：检查所有依赖与 Rust 1.81 的兼容性
